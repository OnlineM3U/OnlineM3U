# Installation Guide

Welcome to OnlineM3U! In addition to our web app, you can install OnlineM3U natively on your desktop for a more integrated, high-performance experience.

## Windows
1. Download the latest `OnlineM3U Setup.exe` file from our releases page.
2. Double-click the `.exe` file.
3. Follow the standard installation wizard prompts.
4. Once installed, you can launch OnlineM3U from your Start Menu.

## Mac
1. Download the latest `OnlineM3U-mac.zip` file.
2. Double-click the `.zip` file to extract it.
3. Drag the extracted `OnlineM3U.app` into your `Applications` folder.
4. If you receive a warning about opening an app from an unidentified developer, right-click (or Control-click) the app and select **Open**.

## Linux

We provide two formats for Linux: `.AppImage` (recommended for most distributions) and `.deb` (for Debian/Ubuntu-based distributions).

### Using the AppImage
1. Download the `.AppImage` file.
2. Make the file executable:
   ```bash
   chmod +x OnlineM3U-*.AppImage
   ```
3. Run the AppImage by double-clicking it, or running `./OnlineM3U-*.AppImage` in your terminal.

### Using the DEB package (Debian, Ubuntu, Mint, etc.)
1. Download the `.deb` file.
2. Install it using `dpkg` or `apt`:
   ```bash
   sudo apt install ./onlinem3u-desktop_*.deb
   ```
3. Launch OnlineM3U from your application launcher.
